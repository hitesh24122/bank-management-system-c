# Bank Management System in C

## About the Project

The Bank Management System is a console-based application developed using the C programming language. This project is designed to perform basic banking operations through an interactive menu-driven interface.

The application allows users to create multiple bank accounts, deposit and withdraw money, view account details, search for specific accounts, identify the richest customer, and calculate the total bank balance.

I developed this project to strengthen my understanding of C programming and improve my logical thinking, problem-solving, and practical coding skills.

## Features

- **Create Account:** Register customers with their name, account ID, and initial balance.
- **Display Accounts:** View details of all registered customers.
- **Deposit Money:** Add money to an existing account.
- **Withdraw Money:** Withdraw money after checking the available balance.
- **Search Account:** Find an account using its unique ID.
- **Richest Customer:** Identify the customer with the highest account balance.
- **Total Bank Balance:** Calculate the combined balance of all accounts.
- **Account Validation:** Check for duplicate account IDs and invalid transaction amounts.
- **Exit:** Safely close the application.

This is a beginner-level educational project. Account information is stored temporarily in memory and is lost when the program closes. Input validation and financial calculations can be improved further.
